# Books & Films Tracker

Учебное Android-приложение для ведения личных списков книг и фильмов. Можно добавлять произведения, распределять их по категориям и отмечать прочитанные книги и просмотренные фильмы.

## Стек

- Java 8;
- Android SDK 31, минимальная версия Android 5.0;
- AndroidX Navigation и RecyclerView;
- локальное хранение данных в SQLite.

## Запуск

Откройте проект в Android Studio, дождитесь синхронизации Gradle и запустите конфигурацию `app` на эмуляторе или устройстве.
